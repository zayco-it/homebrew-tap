# zaYco Homebrew Tap

Homebrew casks for [zaYco](https://zayco.it) apps.

## lidawake

Keep your Mac awake with the lid closed — safely, from one menu-bar switch.

```sh
brew install --cask zayco-it/tap/lidawake
```

Or tap first, then install:

```sh
brew tap zayco-it/tap
brew install --cask lidawake
```

Installs a 14-day free trial. More at **[zayco.it/lidawake](https://zayco.it/lidawake/)**.
Updates are handled by the app itself (Sparkle), so `auto_updates` is set.
